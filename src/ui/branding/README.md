# Putio Manager application icon

The original `putio-manager.png` was generated with OpenAI ImageGen for this project on 2026-11-05 as the requested application-icon replacement. It is the source artwork. The ICO, ICNS and 16/32 pixel PNG files are resampled format exports of that image; no artwork was redrawn. ICO includes 16, 24, 32, 48, 64, 128 and 256 pixel sizes. ICNS includes standard sizes through 1024 pixels. Transparency is retained.

The desktop window and tray use the bundled PNG. Electron Packager uses the matching native ICO or ICNS when building platform bundles. The ICO is also copied into `dist/ui/branding` so a Windows shortcut can use it with an existing trusted executable.
